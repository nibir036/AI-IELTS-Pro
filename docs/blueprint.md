# **App Name**: AI IELTS Pro

## Core Features:

- Personalized Learning Paths: Generate customized learning paths based on the user's current band and target band using the information in Firestore.
- AI-Powered Writing Evaluation: Evaluate writing submissions using the Gemini API and provide detailed feedback aligned with IELTS band descriptors.
- AI-Powered Speaking Evaluation: Evaluate speaking submissions using the Gemini API, converting audio to text, and provide detailed feedback.
- Multilingual Support Tool: Offer initial instructions and explanations in the user's native language (read from Firestore) to enhance accessibility.
- Mock Test Simulation: Simulate full IELTS mock tests with timed sections and realistic question formats (definitions read from Firestore).
- Progress Tracking & Analytics: Track user progress, practice time, and performance metrics using Firestore to visualize improvement.
- Grammar & Vocabulary Practice: Provide targeted grammar and vocabulary exercises with level-based difficulty read from the Firestore lessons.

## Style Guidelines:

- Primary color: Dark teal (#008080) to convey professionalism and trust, suitable for an educational app.
- Background color: Light gray (#F0F0F0), a desaturated version of the primary color that is easy on the eyes and provides a clean interface.
- Accent color: Gold (#FFD700) to highlight key elements like scores, progress indicators, and CTAs, creating a sense of achievement.
- Body and headline font: 'Inter' for a modern, clean, and highly readable sans-serif typeface suitable for educational content. 
- Note: currently only Google Fonts are supported.
- Use clear, minimalist icons to represent different practice areas and features.
- Design a clean, intuitive layout that prioritizes ease of navigation.
- Employ subtle animations to provide feedback and enhance user engagement without being distracting.
